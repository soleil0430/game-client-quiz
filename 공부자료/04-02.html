컬링과 가시성

안 그리는 것이 가장 싸다. 시야 밖·가려짐·뒷면·이미 가까운 픽셀을 어디서 거르는지 나눈다

핵심 개념

가장 빠른 렌더링은 아예 그리지 않는 것이다. 파이프라인 곳곳에 안 보이는 것을 버리는 관문이 있고, 거르는 대상과 단위가 다르다.

기법어디서무엇을 거르나단위
프러스텀 컬링CPU카메라 시야 밖오브젝트의 경계 볼륨
오클루전 컬링CPU다른 물체에 가려진 것오브젝트
백페이스 컬링GPU(래스터화 전)뒤를 보는 삼각형삼각형
깊이 테스트GPU더 가까운 것이 있는 자리픽셀

프러스텀 컬링은 Unity가 자동으로 하며, 오브젝트의 경계 상자가 절두체 여섯 평면 밖이면 목록에서 뺀다. 판정 단위가 오브젝트라서 지형 전체가 메시 하나면 귀퉁이만 보여도 전부 그려진다. 이런 메시는 쪼개야 컬링이 먹는다.

using UnityEngine;

// Renderer가 붙은 오브젝트에 함께 둔다
public class VisibilityGate : MonoBehaviour
{
    readonly Plane[] _planes = new Plane[6];   // 매 프레임 새 배열을 만들지 않는다

    public bool IsInFrustum(Camera cam, Renderer target)
    {
        GeometryUtility.CalculateFrustumPlanes(cam, _planes);   // 절두체 6평면을 채운다
        return GeometryUtility.TestPlanesAABB(_planes, target.bounds);  // 경계 상자 단위 판정
    }

    void OnBecameInvisible() { enabled = false; }  // 보일 때만 필요한 로직을 끈다
    void OnBecameVisible()   { enabled = true; }
}

오클루전 컬링은 벽 뒤처럼 가려진 오브젝트를 뺀다. Unity 기본 방식은 씬을 미리 구워(bake) 가시성 데이터를 만들고 런타임에 조회하므로, 조회 비용과 구운 데이터를 내고 드로우 콜을 사는 것이다. 막힌 실내에서는 크게 남고 개활지에서는 비용만 남는다.

LOD는 화면에서 차지하는 비율에 따라 폴리곤이 적은 메시로 갈아 끼워 정점·셰이딩 비용을 줄인다(LODGroup). 대신 단계별 메시를 다 들고 있어야 해 메모리와 용량은 늘고, 전환 순간 형태가 튀는 팝핑이 보인다.

백페이스 컬링은 화면에 투영된 세 정점이 감기는 방향(와인딩 순서)으로 앞뒤를 가른다. Unity는 시계 방향이 앞면이고 기본이 Cull Back이다. 정점 순서가 뒤집힌 메시가 안쪽만 보이는 것이 이 때문이며, 나뭇잎처럼 양면이 필요하면 Cull Off로 끈다.

깊이 버퍼는 픽셀마다 현재 깊이를 적어 두고 더 가까운 조각만 통과시켜, 그리는 순서와 무관하게 앞뒤를 맞춘다. 값이 비선형으로 저장돼 정밀도가 근평면에 몰리므로 near를 너무 작게 잡거나 far를 과하게 키우면 Z-파이팅이 난다.

모바일(타일 기반 GPU)은 타일 메모리 안에 깊이를 두어 깊이 테스트가 싸고, 가려질 픽셀의 셰이딩을 건너뛰는 하드웨어 기능(PowerVR의 HSR, Adreno의 LRZ)까지 있다. 그래서 데스크톱에서 쓰는 깊이 프리패스가 여기서는 지오메트리를 두 번 처리하는 손해가 되기 쉽다. 단 이 기능은 discard가 있으면 꺼진다. 반대로 CPU 예산이 빠듯해 오브젝트 수를 줄이는 컬링과 LOD는 더 중요하다.

면접에서 이렇게 답한다

  • 프러스텀 컬링과 오클루전 컬링의 차이 — 둘 다 CPU에서 그릴 목록을 줄이지만 프러스텀은 시야 밖을, 오클루전은 시야 안이지만 가려진 것을 뺀다. 프러스텀은 자동이고 오클루전은 베이크와 조회 비용이 들어 씬 구조를 보고 켠다.
  • 백페이스 컬링의 판정 기준 — 화면에 투영된 정점이 감기는 방향으로 앞뒤를 가르고 뒷면을 버린다. 메시 노멀이나 정점 순서가 뒤집히면 판정도 뒤집혀 안쪽만 보인다.
  • LOD의 장단점 — 거리에 따라 단순한 메시로 바꿔 정점과 셰이딩을 아끼지만, 단계별 메시만큼 메모리와 용량이 늘고 전환 순간 팝핑이 생긴다.
  • 깊이 버퍼의 동작 — 픽셀마다 깊이를 저장해 더 가까운 조각만 남기므로 순서와 무관하게 앞뒤가 맞는다. 정밀도가 근평면에 몰려 near/far 비율이 나쁘면 Z-파이팅이 난다.

흔한 오해

  • 오클루전 컬링은 켜기만 하면 이득이다 — 베이크 데이터와 조회 비용이 있어 가릴 것이 없는 개활지에서는 비용만 남는다.
  • 백페이스 컬링이 뒤에 있는 오브젝트를 거른다 — 거르는 것은 삼각형의 뒷면이다. 가려진 오브젝트는 오클루전 컬링, 가려진 픽셀은 깊이 테스트가 맡는다.
  • 프러스텀 컬링은 삼각형 단위다 — 오브젝트의 경계 볼륨 단위라, 거대한 단일 메시는 컬링이 거의 듣지 않는다.
  • LOD는 메모리도 줄여 준다 — 단계마다 메시를 따로 들고 있으므로 메모리와 빌드 용량은 오히려 는다.
