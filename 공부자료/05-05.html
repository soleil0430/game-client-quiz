충돌과 교차 판정

싼 검사로 후보를 추리고 정밀 검사는 최소로. 제곱근과 나눗셈을 피해 식을 세운다

핵심 개념

충돌 판정의 목표는 "겹쳤는가"를 필요한 정밀도로, 가능한 한 적게 계산하는 것이다. n개의 모든 쌍을 보면 O(n²)이라 1,000개만 돼도 499,500쌍이다. 그래서 넓은 단계에서 AABB 겹침을 스윕 앤 프룬이나 공간 분할(그리드, BVH)로 훑어 후보 쌍만 남기고, 좁은 단계에서 그 쌍만 실제 형상으로 검사해 접촉점과 파고든 깊이를 구한다.

AABB는 x, y, z 모든 축에서 구간이 겹칠 때만 겹친 것이라, 한 축이라도 떨어져 있으면 즉시 끝나 매우 싸다. 분리축 정리의 가장 단순한 형태다. 구와 구는 제곱근을 피해 d2 <= (ra + rb) * (ra + rb)로 본다. 캡슐과 구는 캡슐이 "선분에서 거리가 반지름 이하인 점들"이라, 구 중심을 선분에 투영한 매개변수를 0~1로 자른 뒤 그 점까지의 거리를 반지름 합과 비교한다.

분리축 정리(SAT)는 볼록 도형 일반으로 가는 길이다. 둘이 떨어져 있으면 가르는 축이 반드시 존재하고, 그 축은 2차원에서는 변의 법선, 3차원에서는 면 법선과 모서리 외적 중에 있다. 후보 축마다 투영해 한 축이라도 구간이 안 겹치면 즉시 끝내고, 모두 겹칠 때만 충돌이며, 겹침의 최솟값이 밀어낼 방향과 깊이가 된다. 점과 다각형은 반직선을 쏴 변과 만난 횟수가 홀수면 내부로 보면 오목까지 통한다.

광선 계열은 O + tD를 도형의 식에 넣어 t를 푼다. 법선 N인 평면은 t = Dot(N, Q - O) / Dot(N, D)이고, 분모가 0이면 평면과 나란해 교차점이 없다. t가 음수면 광선 뒤쪽이라 걸러내고 분모의 부호로 앞뒷면을 나눈다. 구는 이차방정식이 되어 판별식이 음수면 안 만나고, 삼각형은 교차점을 무게중심 좌표로 안팎 판정한다.

마지막이 터널링이다. 일반 검사는 스텝마다의 위치만 보므로 한 스텝에 벽 두께보다 멀리 이동하면 겹치는 순간이 없어 통과한다. 이전 위치와 현재 위치 사이를 레이캐스트나 스윕으로 검사하거나 Collision Detection을 Continuous로 바꾸면 막는다. 상대 위치 dp, 상대 속도 dv인 두 물체가 가장 가까워지는 시각은 거리 제곱을 미분해 0으로 두면 t = -Dot(dp, dv) / Dot(dv, dv)다. 이 t를 한 프레임으로 자른 뒤 그때 거리를 반지름 합과 비교하면 스윕 판정이 된다.

public class Projectile : MonoBehaviour
{
    public LayerMask hitMask;
    public float radius = 0.1f;
    Vector3 prev;

    // 지난 프레임 위치와 지금 위치 사이를 쓸어 검사한다. 빨라도 뚫리지 않는다
    void Update()
    {
        Vector3 delta = transform.position - prev;
        float dist = delta.magnitude;
        if (dist > 0f && Physics.SphereCast(prev, radius, delta / dist, out RaycastHit hit, dist, hitMask))
            transform.position = hit.point;   // 스텝 도중 맞은 지점으로 되돌린다
        prev = transform.position;
    }
}

면접에서 이렇게 답한다

  • 충돌 판정을 왜 두 단계로 나누나 — 모든 쌍을 실제 형상으로 보면 O(n²)이라 감당이 안 된다. 넓은 단계에서 AABB와 공간 분할로 후보만 추리고, 좁은 단계에서 그 쌍만 정밀 검사한다.
  • 광선과 평면·구·삼각형의 교차는 — O + tD를 도형의 식에 넣어 t를 푼다. 평면은 Dot(N, Q - O) / Dot(N, D)이고 분모가 0이면 나란해 만나지 않는다. 구는 판별식으로 걸러내고 삼각형은 무게중심 좌표로 판정한다.
  • 분리축 정리를 설명하라 — 볼록한 둘이 떨어져 있으면 가르는 축이 반드시 있고 그 축은 면 법선과 모서리 외적 중에 있다. 한 축이라도 투영 구간이 안 겹치면 충돌이 아니고, 모두 겹치면 겹침이 가장 작은 축이 밀어낼 방향과 깊이가 된다.
  • 터널링은 어떻게 막나 — 스텝 사이 경로를 레이캐스트나 스윕으로 검사하거나 Collision Detection을 Continuous로 바꾼다. 총알은 물리 바디 대신 레이캐스트로 처리하는 편이 싸다.

흔한 오해

  • Fixed Timestep을 늘리면 터널링이 줄어든다 — 반대다. 스텝이 드물어져 한 스텝 이동 거리가 커지므로 더 잘 뚫린다. 근본 해결은 스윕이나 CCD다.
  • 넓은 단계를 통과했으면 겹친 것이다 — "겹칠 수도 있다"만 알려주는 보수적 검사라 좁은 단계가 필요하다.
  • 분리축 정리는 아무 도형에나 쓸 수 있다 — 볼록 전용이라 오목한 형상은 볼록 조각으로 나눠야 한다.
  • 점 포함 판정은 모든 변의 같은 쪽인지 보면 된다 — 볼록 다각형에서만 맞다. 오목에는 반직선 교차 횟수의 홀짝을 쓰되, 반직선이 꼭짓점을 지날 때 셀 규칙을 정해 둬야 한다.
